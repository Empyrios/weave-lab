# Advanced Weave Lab roadmap

## v1.0 — Delivered

- Independent mobile-first PWA shell, dark mode, standalone deploy configuration.
- Version-aware rulesets; signed-off Notion references and provisional roster data.
- Isolated damage workbench including versioned denominators and experimental smoothing.
- Deterministic Loom generation, swaps, Cascades, Thread accounting and seed-bank study.
- Exclusive six-line snake draft.
- Synthetic worker-driven policy simulator, sensitivity analysis and data export.
- Metadata-level Battle Report inspector and local evidence registry.
- Automated numeric/logic tests and browser acceptance checks.

## v1.1 — Deepen exact engine validation

1. Implement read-only, **private** pinned engine adapter for Weave v0.2 once there is an approved release commit.
2. Load real exported Battle Reports, run exact replay through Weave's existing `report.ts` logic and compare action sequence, RNG snapshots and ruleset fingerprints.
3. Add turn timeline, event waterfall, KO timing, Essence/Thread per side and audit of Bonus Move provenance.
4. Generate benchmark seed packs for all six lines and target-vs-defence matrices.
5. Add automatic sensitivity exports for Defence smoothing, AP, Thread cost, marker refill and variation under same seeds.

## v1.2 — Balance investigation studio

1. A/B experiment comparison with confidence intervals, paired-seed effect sizes and annotated diffs.
2. Team draft decision tree, counterplay coverage and match-up matrix for entire canonical first-gen roster.
3. Turn-level economy plots and optimal-action opportunity-cost probes. Label search agents as developer assistance, never in-game hints.
4. Rewove spike KPI panels, sustain-vs-burst diagnosis and stalemate detection.
5. Regression discovery: save a failing seed and export exact minimal reproduction inputs.

## v2 — Continuous quality system

1. Read-only sync of pinned private GitHub build/CI metadata with explicit permissions.
2. Opt-in Linear issue attachment for **approved** evidence, not automatic changes to tasks or source code.
3. Signed-off QA gates and coverage dashboard for v0.2/v0.3/v0.4.
4. Reusable test harness library for Game Engine and Lab.
5. Rich charts and analytics over a real consented playtest dataset.

## Not in scope

Commercial multiplayer hosting, art/animation tools, an AI agent that silently modifies canonical balance, or a guarantee of future release dates.
